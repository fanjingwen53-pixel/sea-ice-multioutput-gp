# Archived results

This directory contains compact, derived outputs used in the dissertation:

- synthetic sensitivity metrics and summary;
- March-window and method-comparison metrics;
- March 8 and March 29 two-dimensional prediction grids and summaries; and
- external-product consistency metrics and summary.

Observation-level inputs and large cross-validation prediction tables are not
tracked. They are regenerated locally by the experiment scripts when the
authorised data are available.
